# AI-Shop — دستیار مستقل سایت

این پروژه با پایتون و یک مدل زبانی محلی آماده کار می‌کند. برای تولید پاسخ به سرویس هوش مصنوعی خارجی یا کلید گوگل و OpenAI نیاز ندارد. هر سایت اطلاعات عمومی خودش را به آن می‌دهد؛ هیچ نام، محصول، دامنه یا اطلاعات مشتریِ یک فروشگاه واقعی همراه پروژه منتشر نمی‌شود.

## شروع

روی Linux با Python 3.12 و ترجیحاً ۸ گیگابایت رم:

```bash
bash scripts/setup.sh
```

بار اول حدود ۲٫۵ گیگابایت وزن مدل دریافت و هش آن بررسی می‌شود. در GitHub Codespaces، فایل `.devcontainer` محیط دو هسته و ۸ گیگابایت رم را درخواست و آماده‌سازی را اجرا می‌کند. GitHub فقط کد را نگه می‌دارد؛ مدل باید در Codespaces، کامپیوتر یا سرور خودت اجرا شود. Codespaces با توقف یا پایان سهمیه خاموش می‌شود و میزبانی دائمی نیست.

دو هسته برای اجرای این مدل کافی است، ولی پاسخ‌ها بسته به ورودی و پردازنده ممکن است ده‌ها ثانیه یا چند دقیقه طول بکشند. برای کاربران هم‌زمان بیشتر یا سرعت بالا، منابع قوی‌تر لازم است. مدل آمادهٔ متن‌باز استفاده می‌شود؛ این پروژه آموزش مدل از صفر نیست.

## اتصال سایت

نسخهٔ ۰٫۳ برای اجرای کندتر روی CPU، پیام را به‌صورت کارِ در حال پردازش می‌پذیرد و نتیجه با درخواست‌های کوتاه پیگیری می‌شود. متن پیام دوباره ارسال و تولید دوباره شروع نمی‌شود. اطلاعات کارها فقط موقتاً در حافظه می‌مانند و به سایت ثبت‌شدهٔ همان کلید محدودند؛ جزئیات در [راهنمای API](docs/service.md) است.

برای اجرای مستقل، AI-Shop را روی سرور AI اجرا کن و از بک‌اند سایت با API به آن پیام بده. مدل فقط روی سرور AI نصب می‌شود. تنظیم متغیرهای `AI_SHOP_SITE_ORIGIN` و `AI_SHOP_SITE_TOKEN`، دستور `serve --preload` و قرارداد پیام در [راهنمای سرویس مستقل](docs/service.md) آمده است.

روش اختیاری دیگر برای اجرای مدل داخل همان برنامهٔ پایتونی، کتابخانهٔ `ai_shop` است. یک شناسه و مبدأ ثابت برای سایت تعریف کن و فهرست **فقط محصولات قابل مشاهده برای مردم**، قیمت نهایی بسته‌ها و صفحات عمومی را به آن بده. قرارداد کامل در [راهنمای اتصال](docs/integration.md) و نمونهٔ بدون اطلاعات واقعی در [public-feed.json](examples/public-feed.json) است.

```python
from ai_shop import Assistant, KnowledgeBase

bot = Assistant(
    site_id="example-store",
    origin="https://example.com",
    knowledge=KnowledgeBase("private/knowledge.sqlite3"),
)
result = bot.answer(
    "چای‌ها رو بهم بگو",
    public_data=public_snapshot,
)
```

در هر پیام، `public_snapshot` را از اطلاعات عمومی جاری برنامه بساز تا تغییر قیمت و موجودی همان موقع دیده شود. حساب مشتری، سفارش، پیام خصوصی، قیمت خرید داخلی، رمزها و تنظیمات مدیریتی را به این متغیر نده.

هر سایت، پایتونی یا غیرپایتونی، می‌تواند از API مستقل استفاده کند. سرویس را اجرا و از بک‌اند سایت به آن درخواست بفرست؛ همراه هر پیام، `public_data` تازه را ارسال کن تا قیمت‌ها به‌روز باشند. توکن اختصاصی هر سایت فقط روی سرور می‌ماند؛ در مرورگر یا کد عمومی قرار نمی‌گیرد. این توکن برای احراز هویت سرویس خودت است و کلید یک شرکت هوش مصنوعی نیست. ابزارک آماده نیز در `ai_shop/static/widget.js` قرار دارد و با یک مسیر هم‌مبدأ در سایت کار می‌کند.

## خواندن صفحات عمومی

اگر سایت فید دارد:

```bash
.venv/bin/python -m ai_shop index --site example-store --origin https://example.com --feed https://example.com/.well-known/ai-shop.json
```

برای خواندن محدود صفحات HTML عمومی:

```bash
.venv/bin/python -m ai_shop index --site example-store --origin https://example.com --brand "Example Store"
```

خزنده به مبدأ همان سایت محدود است و حساب، سبد، تسویه و مدیریت را نمی‌خواند. ورود نمی‌کند، کوکی نمی‌گیرد، محدودیت‌های دسترسی را دور نمی‌زند و در حالت HTML از `robots.txt` پیروی می‌کند. سایت‌های کاملاً جاوااسکریپتی یا قیمت‌های پیچیده به فید یا اتصال مستقیم نیاز دارند. تعداد پیش‌فرض حداکثر ۲۵ صفحه و عمق دو است؛ ادعای خواندن نامحدود تمام سایت وجود ندارد.

## یادگیری از چت

بدون رضایت، پیشنهاد یادگیری ذخیره نمی‌شود و آرشیو متن چت ساخته نمی‌شود. با رضایت، مدل فقط می‌تواند یک پرسش عمومی و غیرشخصی پیشنهاد دهد. نام و اطلاعات شخصی، رمز، توهین و اطلاعات ناپایدار مانند قیمت و موجودی برای یادگیری پذیرفته نمی‌شوند. پیشنهاد وارد صف بررسی همان سایت می‌شود؛ تا تأیید مالک و تطبیق پاسخ با یک منبع عمومی موجود، دانستهٔ معتبر محسوب نمی‌شود.

این یادگیری، ساخت حافظهٔ عمومی تأییدشده است؛ وزن‌های مدل با گفت‌وگوی بازدیدکنندگان تغییر نمی‌کنند. جزئیات بررسی، حذف و انقضا در [راهنمای یادگیری](docs/learning.md) آمده است.

ورودی، تاریخچه، منابع و خروجی از نظر واژه‌های توهین‌آمیز شناخته‌شده بررسی می‌شوند و به مدل دستور داده می‌شود توهین را تکرار نکند. تشخیص تمام فحش‌ها و همهٔ زبان‌ها یا تضمین «هرگز» ممکن نیست؛ سیاست باید متناسب با مخاطبان گسترش و آزمایش شود.

## تنظیم منابع

| متغیر | پیش‌فرض | کاربرد |
|---|---|---|
| `AI_SHOP_MODEL_PATH` | فایل مدل در `models/` پوشهٔ اجرای برنامه | مسیر وزن محلی GGUF |
| `AI_SHOP_MODEL_DIR` | `models` | محل دانلود پیش‌فرض |
| `AI_SHOP_THREADS` | `2` | رشته‌های CPU |
| `AI_SHOP_CONTEXT` | `4096` | ظرفیت متن |
| `AI_SHOP_MAX_TOKENS` | `512` | سقف تولید پاسخ |
| `AI_SHOP_ENABLED` | `1` | مقدار `0` مدل را غیرفعال می‌کند |

فقط یک مدل در هر پردازش بارگذاری می‌شود و تولیدهای هم‌زمان صف نامحدود نمی‌سازند. داده‌ها، فایل تنظیمات و وزن‌ها را در Git منتشر نکن. راهنمای حفاظت و محدودیت‌ها در [SECURITY.md](SECURITY.md) است.
